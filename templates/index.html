▶ Blueprint cheatsheet & API usage
Document settings
format"pdf" | "docx" | "pptx"
filenamedownload name, sanitized
title / subtitle / authortitle block + metadata
theme_colorhex accent, e.g. "#2563EB"
orientation"portrait" | "landscape"
page_sizeletter | a4 | legal | a3 | a5
header / footerrunning text on every page/slide
page_numberstrue → "Page X of Y" / slide numbers
title_pagetrue → dedicated cover
Elements
heading{ level 1-3, text }
paragraph{ text }
bullet_list{ items } — strings or {text, level}
numbered_list{ items }
callout{ variant: info|success|warning|danger, text }
quote{ text, attribution? }
code{ language?, text }
table{ headers, rows, col_widths? }
chart{ chart_type: bar|column|line|pie, categories, series }
stats{ items: [{label, value}] }
image{ url | base64, caption?, width? }
divider{ }
spacer{ height in points }
page_break{ }
toc{ } — contents / TOC field / agenda slide

Inline formatting inside any text: **bold**, *italic*, `mono`. Level-1 headings start new slides in PPTX; tables/charts/images/stats get their own slide.

API: POST /generate accepts the blueprint as a raw JSON body too —
curl -X POST http://host/generate -H "Content-Type: application/json" -d @blueprint.json -o out.pdf
